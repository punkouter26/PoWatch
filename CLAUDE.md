Operating rules — naming, the compiler contract, domain integrity, git — are in [AGENT.md](AGENT.md)
and are binding. The short version: trunk-based on `master`, no feature branches unless asked, every
package version lives in `Directory.Packages.props`, and the build must stay at **zero warnings**
(`TreatWarningsAsErrors` is on for every project).

## What this is

PoWatch is a calm, local-first room-observation system for caregivers. A Blazor WebAssembly client
runs vision inference **on-device** (WebGPU / transformers.js) against the device camera; inferred
observations are posted through the BFF boundary to ASP.NET Core Minimal API slices, persisted to
Azure Table + Blob Storage (Azurite locally), and read back as live timelines, archives, shift
handoff reports and optional FHIR export.

`PoWatch.Api` serves the WASM client from the same origin and owns authentication, storage,
telemetry and diagnostics. CORS is intentionally never configured.

## Architecture

Six projects: `PoWatch.Api` (host + Minimal API slices), `PoWatch.Client` (Blazor WASM),
`PoWatch.Application`, `PoWatch.Domain`, `PoWatch.Infrastructure`, `PoWatch.Shared` (DTOs).

`Client` and `Shared` are **trim-analyzer clean** and use source-generated JSON metadata — never
add reflection-based serialization to either. `TargetFramework` deliberately stays in each `.csproj`
rather than moving to `Directory.Build.props`: setting it centrally is evaluated too early for SDK
framework inference and breaks trimming in the WASM and Shared projects.

### Authentication (BFF)

Microsoft Entra OIDC on the `/common` authority, or a dev/test guest bypass, signs into an encrypted
HttpOnly cookie. **The WASM client never sees a token** — it asks `/auth/me` for state. The session
cookie is `SameSite=Strict`, `Secure`, and named via `PoPlatform.SessionCookieName(secure: true)`,
which carries the `__Host-` prefix. Issuer validation is shape-based against `AzureAd:AllowedTenants`.

The kiosk case drives the 24-hour sliding cookie expiry: an always-on wall display must survive an
unattended shift without blanking to `/login`.

## Shared Po conventions

Some files here are **generated** and must not be edited in place:

```
src/PoWatch.Api/Platform/PoPlatform.cs      <- po-shared/src/PoPlatform.cs.tmpl
src/PoWatch.Api/Security/SignInTelemetry.cs <- po-shared/src/SignInTelemetry.cs.tmpl
```

They carry an `<auto-generated>` header. Change the template in the `po-shared/` workspace and run
`python po-shared/sync.py`; `sync.py --check` fails if a copy has drifted.

`PoPlatform` supplies the conventions shared across all eleven Po apps: the `Application` log
property, App Insights connection-string resolution, `__Host-` cookie naming, and the uniform
`/health/live` probe the portfolio dashboard polls.

### Telemetry

Structured logs reach Application Insights through the **Serilog sink** in
`Observability/TelemetrySetup.cs` — and only through it. `AddAzureMonitorTraceExporter` in the OTel
pipeline exports *activities* (spans); it never sees an `ILogger` record, so removing the Serilog
sink silently empties the `traces` table.

Sign-in is recorded once per interactive sign-in from `OnTokenValidated` as a `UserSignedIn` event.
